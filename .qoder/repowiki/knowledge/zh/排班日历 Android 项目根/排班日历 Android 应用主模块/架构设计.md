应用采用典型的 MVVM + Clean Architecture 分层：
- `ui/` 层按功能域划分（calendar、todo、shifts、salary、settings、detail、hours、statistics、component、theme、navigation），每个 Screen 对应一个 Composable 页面及同名 ViewModel。
- `domain/model/` 存放纯 Kotlin 领域模型与工具（CalcUtils、LunarCalendar、HolidayData）。
- `data/` 层包含 Room 数据库（entity/dao/AppDatabase）、Repository 抽象、Preferences（DataStore）以及 Calendar 同步适配器。
- `di/` 通过 Hilt Module（DatabaseModule、PreferencesModule）在 SingletonComponent 中提供单例依赖。
- 入口为 `ScheduleApp`（@HiltAndroidApp Application）和 `MainActivity`（@AndroidEntryPoint），由 `AppNavHost` 统一管理 Navigation Compose 路由与底部 Tab 导航。
- 后台能力通过 Manifest 注册的 Receiver（AlarmReceiver、AnniversaryReminderReceiver、BootReceiver）、Service（CalendarAuthenticatorService）与 Glance Widget（ScheduleGlanceWidget、CalendarGlanceWidget）实现。
- 依赖方向严格单向：ui → domain/data → di；Room schema 通过 KSP 导出至 `schemas/` 目录追踪迁移历史（当前 v5）。
