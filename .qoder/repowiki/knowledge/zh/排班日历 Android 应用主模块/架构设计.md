单模块 Android 应用（`:app`），采用 MVVM + Clean 分层：
- `ui/` 层按功能域划分包（calendar、shifts、hours、salary、settings、detail、todo、statistics、component、theme、navigation），通过 `AppNavHost.kt` 使用 Navigation Compose 类型安全路由统一管理页面跳转。
- `domain/model/` 存放纯 Kotlin data class 领域模型（Shift、ScheduleRecord、SalaryConfig 等）与计算工具（CalcUtils、LunarCalendar），不依赖 Android 框架。
- `data/` 层分为 db（Room 实体+DAO+Database）、repository（封装 DAO 调用并做 Entity↔Domain 映射）、prefs（DataStore 偏好）、calendar（Android Calendar 同步）四个子包，依赖方向单向向上。
- `di/` 使用 Hilt（@HiltAndroidApp 标记 ScheduleApp），通过 DatabaseModule / PreferencesModule 提供单例依赖。
- `reminder/` 提供 AlarmManager 广播接收器与定时任务；`widget/` 基于 Glance 实现 Compose-first 桌面小组件。
- Room schema 导出至 `app/schemas/` 目录，当前版本 v5，迁移策略为 fallbackToDestructiveMigration。
