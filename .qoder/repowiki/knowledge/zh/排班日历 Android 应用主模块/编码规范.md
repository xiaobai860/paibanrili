- 领域模型统一使用 Kotlin data class 定义，并通过常量前缀 BUILTIN_ 标识内置数据项（如 BUILTIN_SHIFT_REST、BUILTIN_STATUS_LEAVE）。
- 软删除通过字段 archivedAt: String? 控制，null 表示有效，非 null 表示已归档，所有实体均遵循此约定。
- Hilt 依赖注入通过 @Module + @InstallIn(SingletonComponent::class) 的 object 声明，并使用 @Provides + @Singleton 暴露单例实例。
- Navigation 路由使用 sealed interface 或 data class 配合 composable<RouteX>() 实现类型安全路由，参数通过 backStackEntry.toRoute<T>() 解析。
- ViewModel 与 Screen 分离，Screen 仅负责 UI 状态展示与用户交互，业务逻辑委托给 ViewModel，依赖通过 Hilt @Inject 注入 Repository。
- Room DAO 与 Entity 成对出现，Entity 使用 @Entity + @PrimaryKey，DAO 方法命名遵循 CRUD 语义（insert/delete/update/getByXxx）。
